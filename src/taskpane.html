Check selected IBANs

Select the cells that hold the IBANs, then check them. The results are written as values in the five columns to the right of the selection.

The five columns to the right already hold data. Insert five new columns for the results? Nothing in the sheet is overwritten.

API key

Key saved:

Paste your ibanchecker.cash API key. It is kept in Office's storage on this device, not in the workbook.

No key yet? Get a free key.

Formulas

  • =IBAN.VALID(A2:A100) TRUE or FALSE
  • =IBAN.ERROR(A2:A100) why an IBAN failed
  • =IBAN.BANK(A2:A100) the bank's name
  • =IBAN.BIC(A2:A100) the bank's BIC
  • =IBAN.CHECK(A2:A100) all five columns

Each IBAN counts as one request on your key. Results are kept for six hours on this device, under a hash rather than the IBAN, so the same IBAN checked again within six hours is not counted.
